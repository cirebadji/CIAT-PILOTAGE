# Guide utilisateur
1. Connectez-vous avec un compte créé par l'administrateur.
2. Le tableau de bord présente les KPI calculés sur les projets en base.
3. Ouvrez « Projets » pour rechercher, filtrer, créer, consulter, modifier ou supprimer un projet.
4. Ouvrez « Cohortes » pour consulter les volumes par cohorte.
5. La page « Analyses » présente les graphiques et propose des filtres.
6. « CIAT AI Analyst » permet de poser une question sur les données. Le mode de démonstration fonctionne sans clé API.
7. Utilisez les liens Export Excel et Rapport PDF pour produire les fichiers.
8. Les données chargées par `seed_demo` sont fictives.
